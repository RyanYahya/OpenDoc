# Literary text

Use this as a soft foundation for the writing, with room for variation and creativity. Its starting character is a restrained, slightly lowered title, an intimate reading measure, relaxed leading, and quiet page numbers. These are defaults, not a fixed rule system. A long title may need smaller type through `titleStyle`; another passage may benefit from different spacing, a different opening alignment, or a wider measure. Serve the voice and reading rhythm rather than reproducing the specimen.

The author line, epigraph, and scene breaks are optional. Do not add them merely to fill space, and do not prescribe a plot, chapter structure, or writing method. An epigraph is supplied inline text; include attribution when needed and never invent a quotation. The native starting layout uses flush paragraphs with small gaps. It deliberately does not use the custom Prose indentation helper.

Use ordinary Paragraph blocks and native Forme flow. SceneBreak takes a stable id and a short lead paragraph; its native unbreakable View keeps the marker with that opening. Put the remaining scene text in following paragraphs so it can paginate. Avoid custom fitting, manual line splitting, absolute-positioned body text, and renderer patches. Preserve IDs, quotations, and reference accuracy. Keep changes for one document local or use options that preserve shared defaults.

The caller's theme supplies visual hierarchy, rhythm, and component treatments; catalog previews use Neutral. Review the adapted PDF. Shared changes also need short and long specimens, scene breaks near page boundaries, a second theme, and a working starter. Preserve unrelated documents and templates.
