# Working with templates

Treat every template as a soft foundation for the document being created. It offers a useful starting composition and design intent, with room for variation and creativity. Let the actual content, reader, and purpose guide the result; use judgment rather than trying to reproduce the specimen exactly.

Typography, spacing, margins, image proportions, and placement are starting values. For example, reduce the title size when a long headline overwhelms the opening; rebalance its surrounding space, or adjust the reading measure when the material benefits. Optional elements can be omitted, moved, or adapted. Preserve a coherent hierarchy and readable flow, not every original measurement. Routine design adjustments within the user's brief do not need additional approval.

Keep document-specific adaptations local to that document or a local layout variant. If a small shared option is useful, preserve existing defaults so other documents do not change accidentally. Do not add a generalized layout engine or automatic fitting machinery for a simple design adjustment.

Distinguish design guidance from functional requirements. Native Forme flow, stable block IDs, accurate evidence, validated data contracts where applicable, and preservation of unrelated documents remain requirements. Review the rendered result after adapting it. Each template's guidance should explain its character and useful defaults while making this freedom explicit.
